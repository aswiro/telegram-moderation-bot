# Security Policy

This repository is a sanitized public showcase.

Do not commit or publish:

- Telegram bot tokens
- database passwords
- `.env` files
- real Telegram user or group IDs
- invite links from production groups
- runtime logs
- database dumps
- private customer or operational data

If you discover a secret or sensitive operational artifact in the repository, please contact the repository owner privately instead of opening a public issue containing the data.

Credentials found in Git history should be treated as compromised and rotated immediately.
